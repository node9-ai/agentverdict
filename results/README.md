# Results

Published runs, one directory per tool, version and corpus version
(`results/<adapter>/<tool version>/corpus-<corpus version>/`), each with
`cases.jsonl` (public split, case by case), `summary.json` and `summary.md`.
node9's runs are here now; every other measured tool's run is added after its
maker has had two weeks to review it. `npm run check-results` checks a run
directory before it is submitted (`CONTRIBUTING.md`).
