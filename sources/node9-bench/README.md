# node9's own lists

The rows in this directory, and the hand-chosen package lists in
`sources/packages.json` and `sources/packages-benign-more/`, were written by
node9 (node9's own tests, the system-operation and exposure designs, the
generated tokens, the everyday installs). They are published as data: the
code that generated them holds the held-out rows too, so it stays private.
Each case still says where it came from (`source_ref`), its labels are
node9's and are reported in the vendor section, never in the headline.
`npm run convert` reads these rows as it reads every outside snapshot.
